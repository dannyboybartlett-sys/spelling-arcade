# 🎯 Spelling Arcade

A fun spelling practice platform for English learners. Teachers set up word lists, and students practice spelling through three engaging games.

## How it works

### For Teachers
1. Open the app, switch to **Teacher** mode
2. Add words (type them or upload an Excel/CSV file)
3. Click **Share Link** to generate a student link

### For Students
1. Open the shared link from your teacher
2. Choose a game and start practicing!

## Games

- **🔤 Letter Jumble** — Rearrange shuffled letters into the correct order
- **📝 Fill in the Blank** — Complete words with missing letters
- **🔗 Word Match** — Match English words with their Chinese translations

## Hosting

This site is hosted on GitHub Pages. The words are encoded in the shareable URL — no server or database required.
